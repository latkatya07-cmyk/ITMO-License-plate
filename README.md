# License Plate Detection & Recognition Pipeline
End-to-end система детекции и распознавания автомобильных номерных знаков. 
Разработана в рамках курса *"Проектирование архитектур нейронных систем"* (ИТМО, 2 семестр)

## Overview
Пайплайн состоит из двух этапов:
1. **Детекция**: YOLOv8 (Ultralytics) настраивается на поиск области номерного знака.
2. **Распознавание**: CRNN (CNN Backbone + BiLSTM + CTC Loss) преобразует кроп номера в текстовую строку.

Архитектура распознавателя реализована на основе базового кода семинара, адаптирована под российский датасет номеров и дополнена инфраструктурой для проведения экспериментов.

### Подготовка данных для CRNN
```bash
python prepare_crnn_data.py
```
### Распознавание (CRNN)
```bash
# Baseline
python train_crnn.py

# Эксперименты
python train_exp1_resize.py
python train_exp2_scheduler.py
```
### End-to-End Pipeline (`pipeline.py`)
Полный процесс детекции и распознавания объединён в один скрипт:
1. **Вход**: изображение автомобиля (`.jpg` / `.png`)
2. **Детекция**: YOLOv8 находит номерной знак, фильтрует по `conf ≥ 0.4`
3. **Кроп & Предобработка**: область вырезается → `grayscale` → ресайз `32×100` → нормализация `[0, 1]`
4. **Распознавание**: CRNN предсказывает logits, CTC-декодер преобразует в читаемый текст
5. **Выход**: консольный лог с текстом и уверенностью + файл `pipeline_result.jpg` с визуализацией

```bash
python pipeline.py external_test/car1.jpg
```

## Results & Experiments
### Детекция номерных знаков (YOLOv8n)
> *Разметка для детекции выполнена вручную с помощью инструмента makesense.ai: рамка проводилась по границам видимой части номерного знака, без учёта перспективных искажений.*

| Метрика | Значение | Интерпретация |
|---------|----------|--------------|
| Precision | `0.992` | Почти нет ложных срабатываний |
| Recall | `0.789` | ~8 из 10 номеров найдены |
| **mAP@0.5** | `0.916` | Хорошая точность локализации |
| **mAP@0.5:0.95** | `0.662` | Хорошая точность при строгих IoU-требованиях |
| F1-score | `0.882` | Сбалансированное качество |
> *Модель обучена на 70 размеченных изображениях, валидация/тест — по 14 изображений. Основные ошибки детекции: частичные перекрытия, блики, нестандартные ракурсы.*

### Эксперименты CRNN

Эксперименты проводились на выборке 2k и 20 эпохах
| Эксперимент | Конфигурация | Описание | CER (val) ↓ | Exact Match Acc ↑ | Вывод |
|:------------|:-------------|:---------|:-----------:|:-----------------:|:------|
| **Baseline** | `32×100`, `lr=1e-3`, `Adam`, 20 эпох | Стандартные гиперпараметры | `0.063` | `0.594` | ✅ Выбран как финальная модель|
| **Exp 1**    | `64×200`, `lr=1e-3`, 20 эпох | Увеличение разрешения входа в 4× | `0.205` | `0.178` | ❌ Сходимость замедлилась, pool-слой нивелирует детали |
| **Exp 2**    | `32×100` + `ReduceLROnPlateau`, 20 эпох | Адаптивное уменьшение LR | `0.129` | `0.308` | ❌ Val Loss монотонно падал, scheduler не сработал |
| **Exp 3**    | `32×100` + `Augmentations`, 20 эпох | RandomAffine, ColorJitter, Flip | `0.334` | `0.024` | ❌ Малый датасет + аугментации = недообучение за 20 эпохах |

### Анализ экспериментов
Базовая конфигурация показала наилучший баланс точности и скорости сходимости. Отрицательные результаты в экспериментах 1–3 объясняются **ограниченным числом эпох (20) и малым объёмом тренировочных данных**

**Тестирование на внешних данных показывает хорошие результаты, модель распознает и считывает российские номера**
